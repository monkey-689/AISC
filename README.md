# Implement water jug problem using A* algorithm 
Abstract:
Solve the Water Jug Problem using A* Search Algorithm

Problem Statement:

A person has two water jugs of capacities 4 litres and 3 litres. Initially, both jugs are empty. Using the operations Fill, Empty, and Transfer Water, determine the sequence of steps required to obtain exactly 2 litres of water in the 4-litre jug using the A* Search Algorithm.
